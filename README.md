#Corporation
Консольное программное обеспечение для учёта сотрудников и продуктов корпорации(без использования БД) 
<! - - суть программы - - >
Основная часть программы находится в папке src\main\kotlin\corporation
Программа реализует консольный интерфейс добавления, удаления, и изменения некоторых параметров для сотрудников и продуктов данной корпорации

Программа написана с использованием языка Котлин, продимонстрована работа с ООП, дата классами, object и с использованием сериализации и json файлов. 

Используется система сборки gradle 8.6

Версия SDK 21jbr
